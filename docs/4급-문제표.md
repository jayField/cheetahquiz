# 4급 문제표 (이모티콘 조합) — 초안

> 5급에서 배운 이모티콘을 2~3개 이어 붙인 조합이에요. 5급을 합격했으면 처음 보는 조합도 뜻을 짐작할 수 있게 5급 이모티콘만 썼어요. 밤을 뜻하는 🌕 만 예외예요 (🌙 는 이제 달비라서요).
> 고칠 곳은 표를 직접 수정하거나 **메모** 칸에 적어 주세요. 확정되면 이 파일을 읽어서 코드에 옮길게요.

## 1. 시험 구성 (제안)

- 총 30문항 · 합격 기준 **70점 이상** (5급과 같아요)
- 조합 81개: **2단어 67개**, **3단어 14개**. 한 시험에 3단어는 6~8문항 정도 나오게 하는 걸 제안해요.
- 피부색·성별이 달라도 정답, 🐆 는 입력칸에 미리 있는 건 5급과 같아요.

## 2. 어순 규칙 (시작 안내 화면에 적을 문구)

> **앞에는 상황(언제 · 어디서 · 왜), 뒤에는 하는 일이나 기분.** 여러 개면 일어난 순서대로 써요.

| 예시 | 읽는 법 |
|---|---|
| 🐆🏫📖 | 학교에서 → 공부해요 |
| 🐆🤧🏥 | 감기 걸려서 → 병원 가요 |
| 🐆🎮💕 | 게임을 → 좋아해요 |
| 🐆🌕🎮😪 | 밤에 → 게임해서 → 피곤해요 |
